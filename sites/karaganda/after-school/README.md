# After School — karaganda

Импорт текущей согласованной версии лендинга. Статические файлы: index.html, styles.css, app.mjs, schedule.mjs и assets/.

Контактные подвалы временно скрыты; данные не удалены. Восстановление — contacts-archive/RESTORE.txt.
Формы работают в прежнем демонстрационном режиме: внешняя заявка не отправляется, показываются контакты города. Это исходный код для ревью, не заявление о готовой CRM-интеграции.

Подкаталог публикации: /after-school/. Дизайн, содержание, фотографии и их разрешение сохранены; большие фотографии перекодированы в WebP по правилам репозитория.

Перед промышленным запуском: владелец согласует интеграцию штатных lead.js, страницы spasibo и аналитики; WhatsApp — по решению пользователя и правилам репозитория. Не менять main и не заявлять о поступлении заявки без подтверждения CRM. Подключение города и продукта в Coolify выполняет владелец.
